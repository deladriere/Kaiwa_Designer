Requirements

  • A browser with Web Serial and Web MIDI support (Chrome or Edge).
  • Kraftor board running Kaiwa firmware with an ATP3011R4-PU AquesTalk pico LSI.
  • USB connection to the computer.

After serial connect, the GUI requests !INFO?. The board replies with model, chip ID, RAM/FRAM layout, and firmware version — shown as FW v… in the header.

Text format

The AquesTalk Pico speaks Japanese, but its input is AquesTalk ASCII phonetic notation — the same romanization used by earlier Kaiwa firmware. It does not accept UTF-8 kanji, hiragana, or katakana; only half-width ASCII romaji and the symbols below.

A phrase may contain at most 127 ASCII bytes. The final carriage-return byte sent to the chip occupies the 128th byte allowed by its protocol. Every utterance must end with a sentence delimiter (usually .).

Building a sentence

Write Japanese readings in romaji, then add prosody marks. One accent phrase may contain at most one ' (or none). Put ' immediately after the mora where the pitch falls (high → low).

Symbol Role
reading lettersRomaji syllables (ka, shi, kyo, n, …)
'Accent nucleus — pitch drop after that mora
-Long vowel (hold the previous vowel)
/Accent-phrase break, no pause
+Softer phrase join (secondary accent), no pause
;Phrase break with a slight lift into the next phrase, no pause
spaceBreath / phrase boundary with pause
,Shorter pause than a space
.End of sentence (with pause)
?End of sentence, question intonation

Examples:

konichiwa.
oha'yo-.
ha'shi.
yorosi'idesuka?

Longer example using -, /, and ' — the Heart Sutra title (Maka Hannya Haramita Shingyo):

maka-/hannya-haramita-/si'n-gyo-.

Here - lengthens vowels, / splits accent phrases, ' marks the pitch drop in si'n, and . ends the sentence.

Tips:

  • Prefer lowercase. Firmware vowel elongation (CC 3 / !VOICE 4th arg) only inserts extra - after lowercase a e i o u.
  • Without ', the accent control has little to work on; use a marked phrase such as oha'yo-. when testing accent strength.
  • Do not start an accent phrase with -.
  • For the full reading-symbol table and tags (numbers, counters), see the ATP3011R4-PU AquesTalk pico LSI datasheet “音声記号列” section: atp3011_datasheet.pdf.

Serial speech — the “what”

  1. Open index.html.
  2. Click Select port and choose the Kraftor USB serial device.
  3. Confirm the readout shows the Kaiwa model and chip ID when reported.
  4. Type phonetic text and click Speak (or press Enter).

Plain serial lines are spoken immediately at 115200 baud. Before Speak, the GUI also sends !VOICE so speed, pitch, accent, and vowel elongation match the dials.

Workflow: serial carries the phrase content; MIDI shapes the voice and triggers stored slots.

MIDI — the “how” and “when”

  1. Click Connect MIDI and allow access if prompted.
  2. Select the MIDI output and channel that match the board DIP switches.
  3. Move the voice dials, or play notes to trigger stored RAM/FRAM slots.
MIDI input Result
Notes 28–47 Play RAM slots 0–19
Notes 48–127 Play FRAM slots 0–79
CC 1 Speed (maps to 50–300)
Pitch bend Pitch register (bend up = higher voice)
CC 2 Accent (0–255)
CC 3 Vowel elongation (0–6 - after each aeiou)

FRAM slots 80–99 stay editable over serial but have no MIDI note. If the chip is busy, the firmware replies !ERR busy; use !STOP to interrupt.

Identify Serial & Identify MIDI

When several Kraftor boards are connected, Chrome does not reliably pair a Web Serial port with a Web MIDI output. Use the identify buttons to hear which physical board each connection reaches.

  • Identify Serial — speaks si-riaru. over the open serial port.
  • Identify MIDI — needs serial and MIDI. Writes mi-di. into temporary RAM slot 0 over serial, then sends MIDI note 28 on the selected channel so that slot plays.

RAM clears at boot, so the MIDI identify phrase lasts only for the current session.

Voice controls

Dials show AquesTalk parameters. Turning Pitch up raises the voice; the numeric readout still shows the chip register (lower register = higher voice). Pure MIDI pitch-bend already follows musical direction.

GUI control Range MIDI Serial
Speed 50–300 CC 1 !VOICE speed pitch accent vowels
Pitch 0–254 Pitch bend
Accent 0–255 CC 2
Vowels 0–6 CC 3

Defaults match firmware: speed 80, pitch 64, accent 100, vowels 0.

Presets: Default, Fast, Slow, High, Low, Drawl. Random invents a new voice; Reset to default restores the firmware defaults.

MIDI channel DIP switches

Switches are read at startup. Move a switch toward its ON marking to enable it. DIP1 = 8, DIP2 = 4, DIP3 = 2, DIP4 = 1. Set the channel to match the GUI, then reset or power-cycle the board. All OFF selects Omni (every channel).

RAM and FRAM sentences

On connect, the GUI learns the bank layout from !INFO?.

  • RAM — 20 volatile slots. Cleared on reset / power-off. MIDI notes 28–47.
  • FRAM — up to 100 persistent slots when the RC256 is present. MIDI notes 48–127 cover slots 0–79; slots 80–99 are serial/GUI only.

Use Reload from board, Save all changed, per-slot Play, and bulk paste fill. Phrase length is capped at 127 bytes for AquesTalk even if an older SAM bank used longer text.

Useful serial commands

!INFO?
!VOICE?
!VOICE 80 64 100
!VOICE 80 64 100 2
!STOP
!SET R 0 konichiwa.
!PLAY R 0
!DUMP R
!SET F 0 ohayo-.
!PLAY F 0
!DUMP F

!VOICE arguments: speed (50–300), pitch (0–254), accent (0–255), optional vowel elongation (0–6). Omit the fourth value to leave elongation unchanged.
